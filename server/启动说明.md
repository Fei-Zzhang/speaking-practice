# Node 后端如何启动

## 正确命令（任选一种）

**方式 A：分两行输入**（推荐，避免粘贴出错）

```bash
cd "/Users/simonezhang/cursor/interview练习/server"
npm start
```

**方式 B：一行**（注意 `&&` 和引号后要有空格）

```bash
cd "/Users/simonezhang/cursor/interview练习/server" && npm start
```

### 常见错误

| 错误写法 | 问题 |
|---------|------|
| `cd "...server"npm start` | `server"` 和 `npm` 粘在一起，目录名错了，**不会**执行 `npm start` |
| 多行命令粘成一行 | 例如 `cd servernpm start` 中间缺空格 |

看到 **「已连接 Supabase」「后端运行在 http://localhost:3003」** 就表示启动成功。

## 端口被占用（EADDRINUSE）

默认端口见 `server/.env` 里的 `PORT`（一般为 **3003**）。

```bash
lsof -i :3003
kill <上面显示的 PID>
```

然后再 `npm start`。

## 与前端一致

`standalone.html` 里 `API_NODE` 需与这里端口一致（默认 `http://localhost:3003`）。

## 学生端登录（门户）

当前为 **门户模式**：学生 **自行注册** 用户名与密码，**登录名即身份**；教师布置 Interview 作业时填写的「学生姓名」须与注册名 **完全一致**。

1. 确认本机已启动 Node：`http://localhost:3003/api/health` 能返回 JSON。
2. 在 Supabase **SQL Editor** 执行过 **`server/supabase-portal-student-v1.sql`**（新增 `users.interview_grading_approved` 等字段）。
3. **Interview 云端批改**（含作业 `submit-audio`、题库自主评测、腾讯云实时流式转写签名）需 **教师** 在「Interview · 云端批改开通」中为学生开通；未开通时仍可使用浏览器本地转写。
4. **Listen & Repeat** 流程与权限 **不依赖** 上述开通，保持独立（见 `Listen&Repeat练习` 目录）。

**离线登录**：不连后端，仅本地练习；无法拉取云端作业；Interview 云端能力视为未开通。

## 腾讯云实时语音识别（Interview）

Interview「题目练习」页中的 **腾讯云实时转写（流式）** 需要：

- `server/.env` 中配置 **`TENCENT_ASR_APP_ID`**（与控制台 API 密钥管理中的 AppID 一致）、**`TENCENT_ASR_SECRET_ID`**、**`TENCENT_ASR_SECRET_KEY`**（可与 `oral-python-backend` 中一句话识别用的密钥相同）。
- 后端提供 **`GET /api/tencent-asr/sign`** 签发临时 WebSocket URL；浏览器直连 `wss://asr.cloud.tencent.com`，**不经过** Listen & Repeat 页面。

若未配置，控制台会提示「腾讯云实时 ASR 签名：未配置」；流式转写不可用，不影响 LNR。

## 学生 Interview 作业提交音频显示「保存失败」

Node 会把录音 **Base64** 写入 Supabase 表 `student_submissions` 的 **`audio_b64`**、**`ref_text`** 列。若未执行迁移，写入会失败。

1. 打开 **Supabase 控制台 → SQL Editor**，执行项目里的 **`server/supabase-assignments-audio.sql`**（为 `student_submissions` 增加 `audio_b64`、`ref_text`）。
2. 重启 Node：`cd server && npm start`。
3. 再让学生提交；若仍失败，看页面上 **完整错误文案**（服务端已返回数据库具体原因），并对照 Node 终端日志。

**常见原因**：未执行上述 SQL；录音文件过大（可缩短答题时间）；学生用户名与教师布置时不一致导致无权提交（会提示「无权提交」而非保存失败）。
